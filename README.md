# Сайт барбершопа Double Cuts

Одностраничный сайт без сборки: три файла и папка с картинками. Ничего устанавливать не нужно.

```
index.html          вся разметка и тексты
css/style.css       оформление, включая мобильную версию
js/main.js          меню, табы прайса, галерея, отзывы
js/booking-data.js  барберы, график, услуги и цены для записи — правите вы
js/booking.js       движок записи (календарь, слоты) — трогать не обязательно
img/                фотографии и иконки
```

---

## Как выложить

**Любой обычный хостинг / FTP** — скопируйте всё содержимое папки в корень сайта. Всё.

**Vercel** — перетащите папку на [vercel.com/new](https://vercel.com/new), фреймворк выбирать
не нужно («Other»). Через минуту получите ссылку.

Проверить локально можно двойным кликом по `index.html` — сайт откроется в браузере
и будет полностью работать, включая запись: календарь свой, ничего стороннего не грузит.

---

## После любой правки CSS или JS

В `index.html` подключение выглядит так:

```html
<link rel="stylesheet" href="css/style.css?v=1">
<script src="js/main.js?v=1"></script>
<script src="js/booking-data.js?v=1"></script>
<script src="js/booking.js?v=1"></script>
```

Увеличьте номер (`?v=2`, `?v=3`, …) — иначе у посетителей, которые уже были на сайте,
останется старая закэшированная версия и они не увидят изменений.

## Что где менять

### Цены

Блоки `<div class="price-list" data-price-panel="...">` в `index.html`.
Пять групп: `cut` (стрижки), `beard` (борода), `combo`, `face` (уход за лицом), `extra`.

Одна услуга — один такой блок. Четыре цены = четыре уровня мастера:

```html
<div class="price-row">
  <div class="price-row__name">Мужская стрижка</div>
  <div class="price-row__vals">
    <div class="price-row__val"><span class="price-row__label">Барбер</span>1200 ₽</div>
    <div class="price-row__val"><span class="price-row__label">Старший</span>1400 ₽</div>
    <div class="price-row__val"><span class="price-row__label">Шеф</span>1600 ₽</div>
    <div class="price-row__val"><span class="price-row__label">Бренд</span>1800 ₽</div>
  </div>
</div>
```

`price-row__label` виден только на телефоне — на компьютере вместо него шапка таблицы.
Оставляйте его на месте, даже если на десктопе он не показывается.

### Мастера на странице (карточки в разделе «Команда»)

Секция `<section id="team">` в `index.html`. Каждая карточка — `<article class="master">`.
Кнопка «Записаться» на карточке ссылается на барбера по его `id` через атрибут `data-barber`:

```html
<button class="btn btn--primary btn--sm btn--wide js-booking" type="button" data-barber="mikhail">
  Записаться
</button>
```

Значение `data-barber` должно совпадать с `id` мастера в `js/booking-data.js` (см. ниже) —
это и есть связь между карточкой на странице и записью в календаре.

Фото кладите в `img/`, пропорции — вертикальные (примерно 3:4), карточка сама обрежет лишнее.

### Контакты, адрес, часы работы

Ищите в `index.html` по номеру `+79950374370` — он встречается в шапке, героя, контактах,
подвале, вакансиях и нижней панели на телефоне. Адрес и часы — в секции `<section id="contacts">`
и в блоке `.hero__info`.

Внизу файла есть блок `application/ld+json` — это данные для Яндекса и Google
(адрес, телефон, часы). Если меняете контакты на сайте, поправьте и там.

### Цвета

В начале `css/style.css`:

```css
--brand:       #5f2691;   /* основной фиолетовый */
--brand-light: #8b46c9;   /* кнопки при наведении, акценты */

```

Поменяете эти четыре — перекрасится весь сайт.

## Запись: как это работает

Кнопки «Записаться» открывают мастер записи в 4 шага: **Мастер → Услуги → Дата и время →
Контакты**. Услуг можно выбрать сразу несколько (из разных разделов) — длительность и цена
складываются. Цена всегда точная, потому что известна и услуга, и уровень мастера.
На последнем шаге — подтверждение с кнопками «Добавить в календарь» (.ics-файл),
«Открыть в YClients» (личная ссылка мастера, если она задана) и «Записаться ещё».

### Время в календаре — предварительное, не бронирование

Раздел «Дата и время» показывает только настоящие часы работы (10:00–22:00 ежедневно, как
на сайте) и не притворяется, что знает занятость мастеров — никакой картины «свободно/занято»
там больше нет, только реальные слоты с шагом 30 минут, в которые помещаются выбранные услуги.

Поэтому на каждом шаге написано, что время **предварительное**: гость выбирает удобный ему
слот, а не бронирует место в графике мастера. Подтверждает точное время администратор —
по телефону, после того как увидит заявку (см. ниже).

Если позже подключите настоящее расписание с занятостью (YClients API или свой сервер) —
смотрите функцию `daySlots()` в `js/booking.js`, она единственная отвечает за список времени.

### Как заявки доходят до вас — Telegram-бот

Когда гость доходит до конца записи, заявка отправляется сообщением вашему Telegram-боту.
Это **не** личный чат `t.me/doublecuts` — Telegram не позволяет сайту писать напрямую в чужой
личный чат по ссылке, только через собственного бота, и только после того, как ему хоть раз
написали. Практическая разница небольшая: вы создаёте бота (2 минуты), пишете ему один раз —
и дальше все заявки с сайта будут падать в переписку с этим ботом в вашем Telegram, то есть
именно туда, где вы их увидите.

Настройка:

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, придумайте
   имя и юзернейм (например `DoubleCutsBookingBot`). В ответ придёт **токен** — длинная строка
   вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
2. Найдите своего бота в Telegram по юзернейму и напишите ему любое сообщение, например
   «привет» — без этого шага бот не сможет писать вам первым.
3. Узнайте **chat_id**: откройте в браузере (вместо `<ТОКЕН>` вставьте токен из шага 1)
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найдите `"chat":{"id":...}`,
   это число и есть chat_id.
4. Откройте `js/booking-data.js`, впишите оба значения:
   ```js
   telegram: {
     botToken: '123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx',
     chatId: '123456789'
   },
   ```
5. Сохраните файл, обновите номер версии у `booking-data.js` в `index.html` (см. раздел
   «После любой правки» выше) — готово, заявки начнут приходить.

Пока оба поля пустые, заявки никуда не уходят: гость всё равно увидит экран «Заявка
отправлена», но вы её не получите. Это специально видно в консоли браузера (F12 → Console) —
там появится предупреждение `Double Cuts: заявка не отправлена…`, если забудете настроить.

Если вместо Telegram удобнее почта — можно использовать [Formspree](https://formspree.io):
зарегистрируйтесь, получите адрес формы и замените вызов `sendToTelegram(booking)` в
`js/booking.js` (внутри функции `goTo`, шаг подтверждения) на `fetch` к вашему адресу Formspree.

**Если юзернейм или бот когда-нибудь поменяются** — повторите шаги 2–4 с новым ботом.

### Мастера, услуги и цены записи

Все данные календаря — в одном файле, `js/booking-data.js`. Длительность услуг в минутах на
исходном сайте нигде не была указана — проставлена реалистично по типу процедуры, поправьте
под себя. Цены — 4 тарифа, совпадают с разделом «Цены» на сайте.

Чтобы добавить или убрать барбера — добавьте/удалите объект в массиве `barbers` (нужны `id`,
имя, должность, `tier` — уровень цены: `barber`/`senior`/`chef`/`brand`, фото, и по желанию
`yclients` — личная ссылка для кнопки «Открыть в YClients» на экране подтверждения) и
соответствующую запись в `schedule` с тем же `id`. Не забудьте карточку на странице
(`data-barber="id"`, см. выше) — иначе кнопка «Записаться» у нового мастера не будет знать,
кого выбрать заранее.
