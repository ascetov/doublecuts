# Сайт барбершопа Double Cuts

Одностраничный сайт без сборки: три файла и папка с картинками. Ничего устанавливать не нужно.

```
index.html      вся разметка и тексты
css/style.css   оформление, включая мобильную версию
js/main.js      меню, табы прайса, галерея, отзывы, модалка записи
img/            фотографии и иконки
```

---

## Как выложить

**Любой обычный хостинг / FTP** — скопируйте всё содержимое папки в корень сайта. Всё.

**Vercel** — перетащите папку на [vercel.com/new](https://vercel.com/new), фреймворк выбирать
не нужно («Other»). Через минуту получите ссылку.

Проверить локально можно двойным кликом по `index.html` — сайт откроется в браузере
и будет работать целиком, кроме виджета записи: сторонний iframe грузится только по `http(s)`.

---

## После любой правки CSS или JS

В `index.html` подключение выглядит так:

```html
<link rel="stylesheet" href="css/style.css?v=1">
<script src="js/main.js?v=1"></script>
```

Увеличьте номер (`?v=2`, `?v=3`, …) — иначе у посетителей, которые уже были на сайте,
останется старая закэшированная версия и они не увидят изменений.

## Что где менять

### Цены

Блоки `<div class="price-list" data-price-panel="...">` в `index.html`.
Пять групп: `cut` (стрижки), `beard` (борода), `combo`, `face` (уход за лицом), `extra`.

Одна услуга — один такой блок. Четыре цены = четыре уровня мастера:

```html
<div class="price-row">
  <div class="price-row__name">Мужская стрижка</div>
  <div class="price-row__vals">
    <div class="price-row__val"><span class="price-row__label">Барбер</span>1200 ₽</div>
    <div class="price-row__val"><span class="price-row__label">Старший</span>1400 ₽</div>
    <div class="price-row__val"><span class="price-row__label">Шеф</span>1600 ₽</div>
    <div class="price-row__val"><span class="price-row__label">Бренд</span>1800 ₽</div>
  </div>
</div>
```

`price-row__label` виден только на телефоне — на компьютере вместо него шапка таблицы.
Оставляйте его на месте, даже если на десктопе он не показывается.

### Мастера

Секция `<section id="team">`. Каждая карточка — `<article class="master">`.
Чтобы добавить барбера: скопируйте соседнюю карточку, замените фото, имя, должность, опыт
и **ссылку на его запись** в атрибуте `data-yclients`:

```html
<button class="btn btn--primary btn--sm btn--wide js-booking" type="button"
        data-master="Имя, должность"
        data-yclients="https://n1283932.yclients.com/company/704044/personal/select-services?o=mXXXXXXX">
  Записаться
</button>
```

Ссылку берут в личном кабинете YClients: **Онлайн-запись → Ссылка на конкретного сотрудника**.
Если убрать атрибут `data-yclients`, кнопка откроет общую запись по всем мастерам.

Фото кладите в `img/`, пропорции — вертикальные (примерно 3:4), карточка сама обрежет лишнее.

### Контакты, адрес, часы работы

Ищите в `index.html` по номеру `+79950374370` — он встречается в шапке, героя, контактах,
подвале, вакансиях и нижней панели на телефоне. Адрес и часы — в секции `<section id="contacts">`
и в блоке `.hero__info`.

Внизу файла есть блок `application/ld+json` — это данные для Яндекса и Google
(адрес, телефон, часы). Если меняете контакты на сайте, поправьте и там.

### Цвета

В начале `css/style.css`:

```css
--brand:       #5f2691;   /* основной фиолетовый */
--brand-light: #8b46c9;   /* кнопки при наведении, акценты */
--brand-pale:  #e7cdff;   /* светлый текст-акцент */
--bg:          #0d0b10;   /* фон страницы */
```

Поменяете эти четыре — перекрасится весь сайт.

## Запись: как это работает

Кнопки «Записаться» открывают окно с двумя вкладками.

**«Выбрать время»** — внутри встроен ваш действующий виджет YClients. Он сам показывает
занятые и свободные окна каждого барбера: сайту не нужно ничего знать про расписание,
всё берётся из вашего кабинета в реальном времени. Кнопка у конкретного мастера открывает
сразу его личное расписание, кнопка в шапке и в футере — общую запись по филиалам.

Ничего настраивать не нужно: меняете график в YClients — сайт показывает новый график.

**«Оставить заявку»** — простая форма с именем и телефоном на случай, если гость
не хочет разбираться с календарём.

### Как включить отправку заявок

Сейчас форма только показывает «Заявка принята» — никуда не отправляет.
В `js/main.js` найдите комментарий `TODO: подключить реальную отправку заявки`.
Там два готовых варианта:

- **Telegram-бот** — создайте бота через [@BotFather](https://t.me/BotFather), возьмите токен
  и `chat_id`, подставьте в запрос.
- **Formspree** — зарегистрируйтесь на [formspree.io](https://formspree.io), укажите почту,
  получите адрес формы и пропишите его в `form.action`.

Пока это не подключено, все заявки идут только через YClients и по телефону.
